# proc-manager-tui

TUI-менеджер процессов на Rust (ratatui) — как rust-sysmon-tui, но с управлением.

## Возможности (план)

- таблица процессов: PID, имя, CPU, RAM, пользователь;
- сортировка по любому столбцу;
- поиск и фильтрация;
- завершение процессов (kill), смена приоритета;
- дерево родитель/потомок;
- горячие клавиши в стиле htop.

## Стек

- Язык: Rust
- Планируемые библиотеки: `ratatui`, `crossterm`, `sysinfo`

## Сборка и запуск

```bash
cargo build --release
cargo run --release
```
